# RZ_Tool_u-boot
U-Boot is used by the Install Utility tool to help install Linux to external memory during the manufacturing phase.

Currently the following boards and MPUs are supported:
* Board: RZG2L SMARC Evaluation Kit / MPU: R9A07G044L (RZ/G2L)
* Board: RZG3S SMARC Evaluation Kit / MPU: R9A08G045 (RZ/G3S)
* Board: RZG3E SMARC Evaluation Kit / MPU: R9A09G047 (RZ/G3E)
* Board: RZG3L SMARC Evaluation Kit / MPU: R9A08G046 (RZ/G3L)
